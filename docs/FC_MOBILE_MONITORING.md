# FC Mate — мониторинг FC Mobile и быстрые промокоды

## Что делает модуль
- Проверяет публичные страницы с активными FC Mobile кодами 10 раз в сутки (примерно раз в 2 часа 24 минуты).
- Проверяет Google News RSS по официальным EA новостям, промокодам, карточкам и мета раз в час.
- Сохраняет публикации и замеченные коды в SQLite, не рассылая один и тот же код повторно.
- При первом обнаружении нового кода немедленно отправляет сообщение во все группы, где FC Mate уже общался и не выключен.
- Передаёт последние публикации и коды в контекст Groq при вопросах об FC Mobile.

## Источники
- EA FC Mobile News: https://www.ea.com/games/ea-sports-fc/fc-mobile/news
- EA redeem FAQ: https://www.ea.com/en-gb/playtesting/news/redeem-code-faq
- FC Mobile Forum code list: https://www.fcmobileforum.com/fcmobile-redeem-codes
- FC Mobile Squad code list: https://fcmobilesquad.com/redeem-code
- Mr Believer Hub code list: https://mrbelieverhub.com/fcmobile-redeem-codes
- Google News RSS queries for EA news, codes, player cards and meta.

## Важные ограничения
- EA redemption portal не предоставляет публичной проверки валидности кода. Поэтому сообщение помечает коды с фанатских сайтов как найденные в сообществе, а не подтверждённые EA.
- Сборщик не вводит код в аккаунт пользователя и не просит EA логин/пароль.
- Источники могут менять разметку или блокировать запросы. Ошибка одного сайта не должна останавливать остальные.
- Первичная загрузка активных кодов может прислать найденные на момент первого запуска коды в уже подключённые группы.
- Карточки, характеристики, цены рынка и составы не превращаются в полноценную структурированную базу: RSS даёт только публикации и краткий контекст. Для этого нужен отдельный проверенный API/источник.
- Изображения в текущем Telegram обработчике пока не анализируются.

## Интервалы и стоимость
- Опрос выполняется внутри текущего процесса Amvera, без отдельного сервера и новой БД.
- Промокоды проверяются 10 раз в сутки; RSS-новости — раз в час. Используются HTTP GET запросы, без платных API.
- Для постоянной истории SQLite должна находиться на подключённом persistent storage.
