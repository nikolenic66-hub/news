# Football News Bot

Telegram-автопубликатор футбольных новостей на Python. Проект независим от футбольного менеджера.

## Что уже заложено

- RSS-сбор новостей с настройкой списка источников.
- DeepSeek API для коротких русскоязычных публикаций с редакционными правилами.
- Защита от повторов по URL и похожему заголовку.
- Поиск реальных фотографий в Wikimedia Commons с проверкой разрешённой лицензии и атрибуцией.
- Автоматическая публикация в Telegram-канал: максимум 10 постов в сутки и интервал между постами.
- PostgreSQL/Neon для хранения очереди и истории.
- Docker-развёртывание на Amvera.
- Никаких секретов в репозитории: ключи передаются через переменные окружения.

## Переменные окружения

Скопируйте значения из `.env.example` в настройки окружения Amvera. Не публикуйте реальные ключи.

Обязательные параметры: `DATABASE_URL`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHANNEL_ID`, `DEEPSEEK_API_KEY`.

Добавьте бота в канал администратором с правом публикации сообщений. Для базы Neon используйте отдельный проект, не базу футбольного менеджера.

## Источники

Список RSS настраивается через `RSS_FEEDS`. Перед промышленным использованием убедитесь, что автоматический доступ и использование материалов каждого источника соответствуют его условиям.

Фото ищутся в Wikimedia Commons. Бот отбирает изображения с допустимой лицензией, сохраняет автора, страницу файла и лицензию. Если подходящая лицензированная фотография не найдена, материал не публикуется автоматически.

## Локальный запуск

1. Python 3.12+
2. `python -m venv .venv`
3. Активируйте окружение и установите зависимости: `pip install -r requirements.txt`
4. Заполните локальный `.env` по примеру `.env.example`.
5. Запустите проверки: `pytest -q`
6. Запустите приложение: `python -m app.main`

## Amvera

В репозитории есть Dockerfile. Подключите репозиторий к отдельному проекту Amvera и задайте переменные окружения в панели управления. Сервис работает как фоновый процесс и сам опрашивает источники; публичный HTTP-порт не нужен.

## Важные ограничения первой версии

- Лимит в 10 постов в сутки является верхним пределом, а не гарантией заполнения канала.
- Модель не должна добавлять факты, которых нет в исходном RSS-материале.
- Фотография из Wikimedia может быть иллюстративной, а не снимком именно описываемого события. Такие публикации помечаются.
- До запуска нужно проверить доступность RSS-источников и создать ключ DeepSeek.
