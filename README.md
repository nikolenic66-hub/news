# FC Mobile Chatmate Bot

Telegram group companion for FC Mobile players. A Russian-speaking AI participant with game knowledge, chat personality, group memory and anti-spam activity controls.

## Setup
1. Create a bot with BotFather and add it to the group.
2. Set `TELEGRAM_BOT_TOKEN` and `AI_API_KEY` in Amvera environment variables.
3. Set `AI_BASE_URL` and `AI_MODEL` for your OpenAI-compatible provider.
4. Deploy with Docker.

Environment options are documented in `.env.example`.
